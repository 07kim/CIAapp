# 画面遷移と状態仕様

- 最終更新日: 2026-10-30
- 製品挙動の詳細は `PRODUCT_SPEC.md` を正本とする。

## 1. 基本遷移

```text
PCホーム
├─ スタート／検索 → アプリ検索メニュー → 対象アプリを起動
├─ CIAタスクバーアイコン → ネットワーク情報を表示
├─ 通知領域 → クイック状態を表示
├─ 時計 → 日時と当月カレンダーを表示
├─ 監視カメラを選択 → ダブルクリック → 起動演出
│  └─ 監視カメラ入口ロック
│     ├─ 不正解 → 認証走査 → ACCESS DENIED → 入力を消して入口ロック
│     └─ 正解 → 認証走査 → ACCESS GRANTED → 監視カメラアプリ
│        ├─ 映像1 → 個別ロック → 動画1
│        ├─ 映像2 → 個別ロック → 動画2
│        ├─ 映像3 → 動画3
│        ├─ 映像4 → 動画4
│        ├─ 映像5 → 動画5
│        ├─ システムファイル → ログ／診断表示
│        └─ ホーム → 確認 → PCホーム＋全ロックリセット
└─ 入退室ログを選択 → ダブルクリック → 起動演出
   └─ 入退室ログアプリ（社長室の確定ログ4件を閲覧）
      └─ ホーム → 確認 → PCホーム
```

映像1・2の個別ロックも、入口ロックと同じ認証走査を挟む。ロック映像を選択しても監視カメラ画面の中央表示は切り替えず、画面全体の上へ半透明暗幕と認証ウィンドウを重ねる。認証前は暗幕クリックまたはEscキーで閉じる。送信後は閉じずに同じウィンドウ内で照合と結果を表示し、不正解時は入力を消して同じ認証ウィンドウへ戻り、正解時は対象動画へ進む。

映像1・2の正解時は、同じウィンドウ内で`ACCESS GRANTED`、錠前の解放、`ARCHIVE LOCK RELEASED`、外周認証線、縦方向の走査を順に見せる。走査の完了時に認証ウィンドウを外し、解除済みになった対象映像を直接表示する。ウィンドウ中央から左右へ分かれる面は表示しない。

監視カメラ入口ロックも、パスワード送信後に画面全体の認証結果へ切り替えない。入力画面を暗い背景として残し、その上へ小さい判定ポップアップを重ねて照合と結果を表示する。不正解時はポップアップを閉じて同じ入力状態へ戻り、正解時は結果の余韻後に監視カメラアプリへ進む。

判定ポップアップは状態が切り替わる瞬間まで保持する。判定時間の途中で一度消し、入力ウィンドウまたは次画面を改めて表示する中間状態は設けない。

スタートメニュー内のアプリは1回のクリックで起動演出へ進む。デスクトップショートカットは1回のクリックでは表示状態を変えず、ダブルクリックまたはフォーカス中のEnterキーで起動する。

デスクトップから各アプリへの移動、および認証後の監視画面への移動では、共通の動的背景を維持したまま前面パネルだけを展開する。背景の再読み込みや単色画面への瞬間的な切替は行わない。

入退室ログアプリはロックなしの閲覧専用画面とする。`2026/11/20`の社長室について、一ノ瀬なつき（`ID-0719`）の`20:00 入室`、`20:15 退室`、`20:30 入室`、`20:45 退室`を順番どおり連続表示する。

## 2. 主要状態

実装では、画面状態を互いに排他的な型として管理する。複数の画面を個別の真偽値で表現しない。

```text
desktop
camera-gate
camera-authenticating
camera-browser
camera-archive-authenticating
camera-video
camera-system-file
access-log
home-confirmation
idle-warning
```

別途、監視カメラアプリ内だけで次を保持する。

```text
cameraGateUnlocked: boolean
unlockedArchiveIds: set of archive IDs
selectedFileId: file ID or null
videoStatus: idle | playing | paused | ended
```

## 3. リセット規則

### PCホームへ戻った場合

- `cameraGateUnlocked`を`false`にする。
- `unlockedArchiveIds`を空にする。
- 選択ファイルを解除する。
- 動画を停止し、再生位置を先頭へ戻す。
- 開いているポップアップを閉じる。
- 放置タイマーを停止する。

### 監視カメラ内でファイルを切り替えた場合

- 現在の動画を停止する。
- 現在の動画の再生位置を先頭へ戻す。
- 解除済み映像の状態は保持する。

### ページ再読み込みの場合

- 初版ではPCホームへ戻し、すべてのロックをリセットする。
- ブラウザ保存領域へ解除状態を永続化しない。

## 4. 放置タイマー

### 計測対象

- `desktop`以外のすべての状態。
- 謎入力画面とポップアップも含む。

### 計測停止条件

- 動画が`playing`の間。
- 認証判定の約2.8秒間。
- PCホーム画面にいる間。

### イベント

- マウス移動
- マウスクリック
- キー入力
- 将来タッチ操作を対象にする場合はタッチ開始

イベントを受けたら警告を閉じ、経過時間を0へ戻す。イベントの高頻度発生で処理が重くならないよう、マウス移動は間引いて扱う。

### 時系列

```text
0秒    計測開始
10秒   残り10秒警告を表示
20秒   PCホームへ移動し全ロックをリセット
```

## 5. 確認画面

手動でホームへ戻る場合のみ表示する。

```text
ホーム画面に戻りますか？

[戻る] [キャンセル]
```

- `戻る`: PCホームへ移動し、該当する状態をリセットする。
- `キャンセル`: 元の画面へ戻り、放置タイマーを0から再計測する。
- 放置による自動復帰では確認を表示しない。
